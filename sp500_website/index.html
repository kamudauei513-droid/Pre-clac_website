01 / THE RESEARCH

Start with the past.

I chose the S&P 500 because it shows long-term growth, and compound interest can be expressed using a exponential function. By using historical data to assume annual return, I can use that assumed annual return rate in a compound interest formula to estimate how an investment can grow over time. This model will not predict actual portfolio growth, but it can be used to understand the math of compound growth.

02 / THE SCENARIO

Meet Yousef.

A fictional scenario to explore a mathematical idea.

Y
STARTING AGE18

After graduating high school, Yousef receives $10,000 from his parents and grandparents.

His grandfather suggests investing the money in an index fund that tracks the S&P 500. Yousef decides to invest the full amount and contribute another $1,000 every month.

$$10,000Initial investment · P
↗$1,000Monthly contribution
“

What could happen if I keep investing over a lifetime?

— Yousef's question
THE ASSUMPTION

One rate. A long time horizon.

Yousef's model assumes a constant annual return of 10.99%, compounded monthly. Real returns vary and are never guaranteed.

10.99%assumed annual return

03 / THE MATHEMATICS

Build the model step by step.

The equation combines the original investment with the future value of monthly deposits.

01

Grow the initial investment

The compound interest formula models how the original $10,000 grows over time.

A = P(1 + r/n)nx
P = 10,000 · r = 0.1099 · n = 12
02

Account for monthly deposits

Each $1,000 deposit grows for a different number of months. Together, their future values form a geometric series.

C = 1000(M + M2 + ··· + M12x)
For end-of-month deposits, the exponents run from 0 to 12x − 1.
03

Use the geometric series formula

Let M be the monthly growth factor. The sum can be simplified into a single expression.

M = 1 + r/12
C = 1000 · M12x − 1M − 1
THE FINAL MODEL

Combine both parts.

y = 10000(1 + 0.1099/12)12x
+ 1000 (1 + 0.1099/12)12x − 10.1099/12

yEstimated portfolio value in dollars

xYears since age 18 (0 ≤ x ≤ 100)

rAssumed annual return: 0.1099

nCompounding periods per year: 12

This version assumes deposits are made at the end of each month and the same rate applies every month.

05 / CONCLUSION

Exponential growth is powerful.
Assumptions matter.

This model demonstrates how compounding and regular contributions can produce exponential growth over time. But a mathematical model is only as realistic as its assumptions: actual market returns fluctuate, and past performance does not guarantee future results.
