Real life data and explanation.

I chose the S&P 500 because it shows long-term growth, and compound interest can be expressed using a exponential function. By using historical data to assume annual return, I can use that assumed annual return rate in compound interest formula to estimate how an investment can grow over time. This model will not predict actual portfolio growth, but it can be used to understand the math of compound growth.

For each year, I averaged the annual returns reported by four sources. Then I calculated the arithmetic mean of the 98 yearly averages.

What each source contributes

  • NYU Stern / Damodaran: historical stock-market return data used as one comparison series.
  • Slickcharts: annual S&P 500 return figures used as a second comparison series.
  • Macrotrends: long-run index history and return context used as a third comparison series.
  • OfficialData: a historical investment-growth illustration used as a cross-check. Its total-return and dividend assumptions may differ from the other sources.

Method: the displayed 10.99% is the arithmetic mean of the four listed annual-return values in the table's average row. These series may use different conventions, so this is an estimate assembled for a school model, not an independently verified investable return series. Check each source's definitions before presenting it as an exact like-for-like comparison.

Using the annual average returns collected from NYU, Slickcharts, Macrotrends, and OfficialData.org, I made a historical growth model and compared it with an exponential compound-interest model. Both models have an initial investment of $10,000 and is left untouched for the same 98-year period, from 1928 to 2025, without additional contributions.

Why the model differs from reality

The compound-interest formula provides an idealized representation of investment growth. It assumes a constant rate of return in every compounding period(10.99% in this scenario), where as the actual annual returns fluctuate. Some years produce substantial gains, while others produce losses. Consequently, the model's predicted value can differ significantly.

Another limitation is that the arithmetic mean of annual returns is not the same as the compound annual growth rate. The arithmetic mean calculates the average of the yearly percentages, but cumulative investment growth depends on the product of the yearly growth factors. Therefore, using the arithmetic mean as a constant annual rate does not necessarily reproduce the historical investment's final value.

The formula itself is not mathematically incorrect. The main source of error is the assumption that a historical arithmetic average will behave like a constant annual return in the future. The model also excludes factors such as investment fees, taxes, inflation, and differences in dividend treatment between data sources. It should therefore be interpreted as a mathematical projection rather than an exact prediction of investment performance.

Exponential equation.

This is Yousef. He is 18. His parents, and grandparents gave him $10,000 right after he graduated high school. They told him he could do whatever he wanted with the money.

His grandfather suggested investing it. Specifically, in an index fund that tracks the S&P 500.

Yousef decides to invests all $10,000 (P) of his money, planning to contribute $1,000 every month.

I will assume the annual return rate is 10.99%

Building the exponential model step by step

Compound interest formula

A = P(1 + r/n)nx
P = 10,000 · r = 0.1099 · n = 12

Monthly deposits and

Each $1,000 deposit grows for a different number of months. Together, their future values form a geometric series.
Ex.The $1,000 invested in the first month will grow for 12 months but the $1,000 invested in the twelveth month will only grow for a month

C = 1000(M + M2 + ··· + M12x)

Use the geometric series formula

Multiplying the entire sum by the common ratio (M) and subtract the original sum (S) from this new equation (M ⋅ S). This cancels out all the middle terms.

SM = ( M13^x + M12^x + M11^x + ··· + M4^x + M3^x + M2^x )
- S = ( M12^x + M11^x + M10^x + ··· + M3^x + M2^x + M1^x )
SM - S ( M13^x + 0 + 0 + 0 + ··· + 0 + 0 + 0 + M1^x )

This can be simplified to

SM - S = ( M13^x + M1^x )

S(M-1) = M( M12^x - 1 )
S = M(M12x − 1)(M − 1)

Put the simplified sum back into

C = 1,000 ( S )
C = 1,000 · M(M12x − 1)(M − 1)
C = 1,000M · (M12x − 1)(M − 1)

Substitue M for 1 + r/n

C = 1,000(1+r/n) · (1+(r/n)12x − 1)( r/n )

Combine A and C to get the final equation

y = 10,000 ( 1 + 0.109912 ) + 1,000 (( 1 + (0.109912)12x − 1))0.109912( 1 + 0.109912) { 0 ≤ x ≤ 100 }

Yousef's scenario's exponential model

Read the model mathematically.

The equation, table, graph, and interpretation below use the same assumptions.

1. Variables and parameters

x is the number of years since Yousef starts investing at age 18 (years). y is the estimated account value (US dollars), so x is independent and y is dependent.

  • P = $10,000: initial deposit at x = 0.
  • S = $1,000: deposit at the end of each month.
  • r = 0.1099: assumed nominal annual rate, or 10.99%.
  • n = 12: monthly compounding periods per year.

2. Starting point and domain

At x = 0, no monthly deposits have yet been made and the initial deposit has not grown: y = $10,000. The starting coordinate is (0, 10,000).

Mathematical domain: all real x for the exponential formula, although negative time is not meaningful in this story. Realistic domain: 0 ≤ x ≤ 100, representing age 18 through age 118.

Over the realistic domain, the range is approximately $10,000 ≤ y ≤ $6,719,364,416 (rounded to the nearest dollar at age 118). This large result reflects the constant-rate assumption, not a reliable forecast.

3. Parent function and transformations

The exponential parent function is f(x) = bx, where b > 1. Here the monthly base is M = 1 + r/12 and the exponent is 12x because there are 12 months per year.

Rewriting the model gives y = (P + S/(r/n))M12x − S/(r/n). Compared with M12x, the coefficient (P + S/(r/n)) vertically stretches the curve, the factor 12 in the exponent makes the horizontal input measured in years, and subtracting S/(r/n) shifts the full mathematical curve downward. The deposits also change the scale and shape compared with a principal-only model.

4. Asymptote and key features

For the unrestricted exponential formula, the horizontal asymptote is y = −S/(r/n), approximately y = −$109,194. This is a mathematical feature as x approaches negative infinity; it is not a realistic account value. On Yousef's realistic domain x ≥ 0, the model starts at $10,000 and grows without approaching a finite horizontal limit.

The graph increases because the assumed monthly growth factor M is greater than 1 and the monthly contributions are positive. Its steepening curve shows that earlier gains can themselves earn returns later.

5. Extension question. When could Yousef reach $1 million?

Question: Approximately how many years would it take for the account to reach $1,000,000?

Let (r/n) = 0.1099/12 and M = 1 + (r/n). Starting with y = PM12x + S(M12x − 1)/(r/n), collect the exponential terms:

y + S/(r/n) = (P + S/(r/n))M12x

Divide, then take natural logarithms:

x = ln((y + S/(r/n))/(P + S/(r/n))) / (12 ln M)

Substituting y = 1,000,000, P = 10,000, S = 1,000 and r/n = 0.1099/12 gives x ≈ 20.39 years. Yousef would be about 38.4 years old. This is a model estimate, not a guarantee.

6. Inverse function

For the model y = (P + S/(r/n))M12x − S/(r/n), solve for x:

y + S/(r/n) = (P + S/(r/n))M12x

(y + S/(r/n))/(P + S/(r/n)) = M12x

ln((y + S/(r/n))/(P + S/(r/n))) = 12x ln(M)

f−1(y) = ln((y + S/(r/n))/(P + S/(r/n))) / (12 ln(M))

The inverse takes a target portfolio value and returns the estimated number of years needed to reach it. For Yousef's realistic model, use target values y ≥ $10,000.

7. Sensitivity analysis

After 20 years, the model estimates approximately:

  • At 5% annual return: $438,160
  • At 8% annual return: $638,288
  • At 10.99% annual return: $953,667

The assumed rate changes the result dramatically: at 20 years, the 10.99% scenario is more than twice the 5% scenario. This demonstrates why choosing a return assumption matters at least as much as doing the calculation correctly.

8. Why this model is useful and its limits

An exponential model is appropriate for illustrating compound growth because each period's growth is applied to the existing balance, while regular deposits add new money that can also grow. The formula is transparent and lets the reader test how time, deposits, and rate affect the outcome.

However, real S&P 500 returns fluctuate and can be negative. The model assumes the same 10.99% nominal rate every year, monthly compounding, constant $1,000 end-of-month deposits, no withdrawals, and no fees, taxes, or inflation. It does not guarantee actual performance. Historical annual-return series may also differ in dividend treatment and definitions, so the 10.99% mean should be described as an illustrative assumption rather than a prediction.
